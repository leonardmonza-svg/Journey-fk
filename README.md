# Journey-fk

Website panduan dan informasi perjalanan masuk Fakultas Kedokteran (FK).

## 🚀 Fitur & Halaman
- **Beranda**: Informasi umum dan sambutan.
- **Peta Jalur Masuk FK**: SNBP, SNBT, Jalur Mandiri, dan IUP/Internasional.
- **Timeline 3 Tahun**: Rencana belajar dari kelas 10, 11, hingga 12 SMA.
- **Profil Alumni & Bukti**: Cerita dan testimoni alumni yang berhasil lolos FK.
- **Untuk Orang Tua**: Panduan dan estimasi biaya serta peran orang tua.
- **Biaya & Program**: Simulasi biaya dan program bimbingan.
- **Konsultasi WhatsApp**: Fitur interaktif untuk konsultasi langsung.

## 🛠️ Teknologi
- [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [TypeScript](https://www.typescriptlang.org/)
- [Lucide Icons](https://lucide.dev/)
- [Motion](https://motion.dev/)

## 💻 Cara Menjalankan Secara Lokal

1. Clone repositori:
```bash
git clone https://github.com/leonardmonza-svg/Journey-fk.git
cd Journey-fk
```

2. Install dependensi:
```bash
npm install
```

3. Jalankan server dev:
```bash
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser Anda.
